# /codigos_pinns/README.md

Códigos exemplos da proposta do livro **Introdução a PINNs**, de Pedro Henrique de Almeida Konzen, submetida para avaliação do corpo editorial da série Notas em Matemática Aplicada (NoMA) da Sociedade de Matemática Aplicada e Computacional (SBMAC).

## Pastas

* './redes_neurais_feedforward/'

    Códigos exemplos associados ao **Capítulo 2 - Redes neurais feedforward**.

* './pinns/'

    Códigos exemplos associados ao **Capítulo 3 - Redes informadas pela física**.
